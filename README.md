# InternBuddy-AI
### AI-Powered Internship Onboarding Assistant

InternBuddy AI merupakan aplikasi web yang dirancang untuk membantu mahasiswa mempersiapkan diri, beradaptasi, dan menjalani proses magang secara lebih terstruktur.

## Tentang Proyek
Proyek ini dikembangkan sebagai Capstone Project IBM SkillsBuild dalam program **IT – AI Agent for Programming**.
InternBuddy AI berperan sebagai pendamping digital bagi mahasiswa, khususnya yang baru pertama kali menjalani magang, melalui panduan, pengelolaan tugas, refleksi, dan asisten interaktif yang disesuaikan dengan konteks pengguna.

## Fitur Utama
- **Dashboard Personal** — Menampilkan informasi dan ringkasan perkembangan magang.
- **Checklist Onboarding** — 14 tugas onboarding yang terbagi dalam 5 kategori.
- **Panduan Magang** — 6 panduan praktis untuk membantu mahasiswa selama magang.
- **Asisten AI** — Memberikan respons kontekstual berdasarkan kata kunci, profil, dan fase magang pengguna.
- **Refleksi Harian** — Membantu pengguna mencatat pengalaman dan pembelajaran selama magang.
- **Pelacakan Progres** — Menampilkan perkembangan penyelesaian onboarding.
- **Manajemen Profil** — Memungkinkan pengguna mengelola informasi profil magang.

## Implementasi AI Agent
Asisten pada InternBuddy AI menggunakan pendekatan *rule-based*, *keyword matching*, dan template respons kontekstual untuk memberikan panduan yang relevan berdasarkan informasi profil serta tahapan magang pengguna.
